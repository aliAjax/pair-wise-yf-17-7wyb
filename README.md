# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面包含音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页，并在其上补齐「维护放行」闭环。

## 维护放行规则

- **每根音管只保留一条有效结果**：新批次放行后，旧的有效结果原地转为只读历史（保留接管来源与时间），永不删除，可形成多级历史链。
- **环境红线**：温度低于 10℃、高于 30℃，或湿度高于 70% 时，本次测量只记为「待复测」，不得放行；批次仍处于记录中，等待复测。
- **整批硬阻断**：音分偏差绝对值超过 8 音分、簧片音栓簧片状态异常，或同一音栓缺少测量结果时，维护批次整批保持「待复核」；旧结果与既有批次快照均不变。
- **放行事务**：仅闸门全部通过时才提交——接管旧结果、生成不可变批次快照；任何阻断都不会产生结果或快照。
- **同步**：规则口径在工作台、单次维护报告、异常统计三处共用；所有数据通过浏览器 localStorage 持久化，多标签页自动同步。

## 模块结构（不新增依赖或服务）

```
src/
  types.ts                 领域模型（批次 / 测量 / 结果 / 快照）
  business/
    rules.ts               规则校验：阈值、环境判定、批次放行闸门（纯函数）
    storage.ts             存储：localStorage 持久化、useSyncExternalStore、放行事务
    report.ts              报告视图数据：单次维护报告 + 异常统计（纯派生）
    seed.ts                演示数据（历史批次经同一闸门放行，含复调接管链）
  components/
    Workspace.tsx          调音工作台：批次管理、测量录入、覆盖矩阵、放行闸门
    ResultLedger.tsx       音管结果台账：唯一有效结果 + 只读历史链
    ReportView.tsx         单次维护报告页（放行前后均可查看，快照留痕）
    AnomalyStats.tsx       异常音管标记与统计
    MetricBar.tsx          顶部关键指标
  react-shim.d.ts          项目内最小 React 类型垫片（不引入 @types/react）
```

规则校验（`rules.ts`）、存储与事务（`storage.ts`）、报告视图（`report.ts` + `components/`）相互分离：后两者只读规则模块的纯函数，规则模块不依赖任何其他业务模块。

## 技术栈

React 19 + Vite + TypeScript，浏览器 localStorage 持久化，无额外运行时依赖。
