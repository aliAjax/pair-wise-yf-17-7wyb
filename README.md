# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

给管风琴维护人员使用的音管调音记录前端项目，可记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注，并在调音记录之上补齐“维护放行”闭环。

## 维护放行规则

- **每根音管只有一条有效结果**：按「场馆 / 音栓 / 音管编号」唯一，存放在有效结果台账中。
- **环境闸门**：温度低于 10℃、高于 30℃ 或湿度高于 70% 时，本次测量只记为「待复测」，不放行、不接管当前结果。
- **整批待复核**：音分偏差绝对值超过 8 音分、簧片状态异常，或同一音栓存在缺测音管时，整个维护批次保持「待复核」，旧有效结果与批次快照均不变。
- **复调接管**：对同一音栓发起新批次并复调成功放行后，上一条有效结果保留为只读记录，由本次结果接管；批次放行瞬间冻结快照，之后只读。
- 报告、异常统计与浏览器 localStorage 持久化随操作实时同步。

## 模块结构（规则 / 存储 / 报告视图分离，不增依赖或服务）

- `src/domain/types.ts`：领域模型（批次、测量尝试、有效结果、只读档）。
- `src/domain/rules.ts`：纯规则校验——环境闸门、缺陷判定、批次裁决、放行快照、复调接管。
- `src/business/storage.ts`：localStorage 持久化与放行动作（新建批次、录入/复调、申请放行）。
- `src/business/seed.ts`：首次打开的演示数据（含已放行、待复核、待复测与复调只读样例）。
- `src/business/report.ts`：单次维护报告视图模型、跨批次异常统计与 JSON 导出。
- `src/ui/*`：React 视图——工作台、报告页、异常统计、有效结果台账。
